# Figma Copy

Превращает блоки из Figma в готовый код: **React + Tailwind**, HTML, Vue 3 или
React + CSS-модули. Выделяете фрейм в Figma — получаете вёрстку с живым
превью, картинками, иконками (SVG) и дизайн-токенами. Auto-layout становится
flexbox, переменные Figma — классами вроде `bg-primary-500`.

Проект состоит из двух частей: **приложения** (запускается локально) и
**плагина для Figma**, который с ним работает.

## 1. Запуск приложения

Требуется Node.js 20+.

```
git clone https://github.com/YpCIIIaK/figma-to-code.git
cd figma-to-code
npm install
npm run dev
```

Приложение откроется на http://localhost:3000. Держите его запущенным,
пока пользуетесь плагином.

## 2. Подключение плагина в Figma

1. Откройте **десктопную** Figma (в браузерной версии подключить плагин с диска нельзя).
2. Откройте любой файл, затем меню
   **Plugins → Development → Import plugin from manifest…**
   и выберите `figma-plugin/manifest.json` из папки проекта.
   Это делается один раз.
3. Выделите фрейм (или несколько) и запустите
   **Plugins → Development → Figma Copy — Send to app**.
4. Нажмите **Сгенерировать**, выберите формат и нажмите **Копировать**.

Если приложение запущено не на порту 3000, укажите его адрес в поле в шапке
плагина (разрешены порты 3000–3005).

## Для разработчиков

- `npm test` — тесты конвертера.
- `npm run build:plugin` — пересобрать движок, вшитый в `figma-plugin/ui.html`,
  после правок в `src/lib/figma/` (иначе тесты упадут).
